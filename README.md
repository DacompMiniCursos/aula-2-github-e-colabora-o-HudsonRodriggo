# Buscador de Pares


## Descricao

Programa em Python que encontra todos os pares de numeros em um vetor que somam um valor alvo.


## Estrutura do projeto

buscador-de-pares/
├── buscador.py   # Script principal
└── README.md     # Documentacao do projeto


## Pre-requisitos

Python 3.x instalado na maquina.


## Como instalar

1. Instale o Python em https://python.org
2. Baixe o arquivo buscador.py
3. Abra o terminal na pasta do arquivo


## Exemplos de uso

Execute o comando abaixo no terminal:
python buscador.py

Com os valores padrao, a saida sera:
Pares encontrados:
(3, 12)
(6, 9)
(7, 8)

Voce pode personalizar o vetor e o valor alvo editando as linhas abaixo no arquivo buscador.py:
vetor = [1, 3, 6, 7, 8, 9, 10, 11, 12, 18]
alvo = 15

Substitua os numeros do vetor e o valor do alvo pelos que desejar!
